# LASTLIGHT ⚔️
### Five enter. One remains.

A 5-player online multiplayer battle royale game.

**Created by Sajib Ayan — October 2026**

🎮 Play here: https://last-light-one.vercel.app

## How to play
- Go to the game link above
- Enter your name → click **With Friends**
- **Create a room** → share the 6-letter code with 4 friends
- When all 5 players join → the match starts automatically
